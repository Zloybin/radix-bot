# AnkiConnect: памятка по нужным методам

Все запросы AnkiConnect отправляются в `http://127.0.0.1:8765` как JSON. В примерах используется API версии `6`.

```json
{
  "action": "названиеМетода",
  "version": 6,
  "params": {}
}
```

Стандартный ответ имеет вид:

```json
{ "result": "…", "error": null }
```

`error: null` означает, что вызов обработан без ошибки. При `result: false` у GUI-методов обычно не выполнено необходимое условие (например, Anki не находится в режиме повторения).

---

## `guiDeckReview`

### Что делает

Запускает обычный режим повторения Anki для указанной колоды. Anki сам выбирает следующую карточку по своим настройкам и расписанию.

### Когда применять

В начале собственного сценария повторения: например, пользователь выбрал колоду в вашем интерфейсе, и нужно перевести основное окно Anki в режим review.

### Параметры

| Параметр | Тип | Обязателен | Значение |
|---|---:|:---:|---|
| `name` | string | да | Полное имя колоды, включая уровни: `"Японский::N5"` |

```json
{
  "action": "guiDeckReview",
  "version": 6,
  "params": { "name": "English::Verbs" }
}
```

Возвращает `true`, если переход к повторению удался, иначе `false`.

> Это именно управление интерфейсом Anki, а не выбор произвольной карточки по её ID.

---

## `guiCurrentCard`

### Что делает

Возвращает данные карточки, которая сейчас показана в окне повторения; вне режима повторения вернёт `null`.

Полезные поля результата:

| Поле | Смысл |
|---|---|
| `cardId` | ID текущей карточки |
| `question` / `answer` | HTML вопроса и ответа |
| `deckName`, `modelName`, `template` | колода, тип заметки и шаблон |
| `fields` | исходные поля заметки с порядком |
| `buttons` | доступные номера оценок для этой карточки |
| `nextReviews` | подписи интервалов, соответствующие кнопкам |

```json
{ "action": "guiCurrentCard", "version": 6 }
```

### Когда применять

После `guiDeckReview` и после каждого ответа, если внешний интерфейс должен показать актуальную карточку или сверить, что Anki всё ещё в review-режиме. Не используйте сохранённые ранее `buttons`/`nextReviews` для следующей карточки: они могут измениться.

---

## `guiShowAnswer`

### Что делает

Переводит текущую карточку в состояние «показать ответ» в интерфейсе Anki.

```json
{ "action": "guiShowAnswer", "version": 6 }
```

Возвращает `true` в режиме повторения и `false` вне его.

### Когда применять

Когда пользователь запросил раскрытие ответа во внешнем интерфейсе. Это обязательный шаг перед `guiAnswerCard`: Anki не примет оценку, пока ответ не показан.

---

## `guiAnswerCard`

### Что делает

Отвечает **на текущую отображаемую карточку** и применяет её к расписанию Anki.

### Параметры

| Параметр | Тип | Значение |
|---|---:|---|
| `ease` | integer | оценка: `1` — Again, `2` — Hard, `3` — Good, `4` — Easy |

```json
{
  "action": "guiAnswerCard",
  "version": 6,
  "params": { "ease": 3 }
}
```

Возвращает `true` при успехе. Значение `ease` выбирайте только из `guiCurrentCard.result.buttons`: на некоторых этапах обучения не все четыре кнопки доступны.

### Надёжная последовательность

1. `guiCurrentCard` — прочитать карточку и доступные оценки.
2. `guiShowAnswer` — показать ответ.
3. `guiAnswerCard` с выбранным `ease`.
4. `guiCurrentCard` — получить следующую карточку либо `null`.

## `answerCards`

### Что делает

Пакетно отвечает на карточки **по их ID**, не опираясь на текущую карточку в GUI. Перед каждым ответом AnkiConnect запускает таймер карточки. Для каждой существующей карточки возвращается `true`, для несуществующей — `false`.

```json
{
  "action": "answerCards",
  "version": 6,
  "params": {
    "answers": [
      { "cardId": 1498938915662, "ease": 2 },
      { "cardId": 1502098034048, "ease": 4 }
    ]
  }
}
```

Результат: `[true, true]` — в том же порядке, что и `answers`.

### Когда применять

Для импорта уже принятых оценок из внешнего тренажёра или для программной обработки набора известных карточек. Это не замена обычному GUI-циклу: если пользователь учится в самом Anki, предпочтительнее `guiShowAnswer` → `guiAnswerCard`.

> Осторожно: метод реально меняет расписание. Проверяйте ID и `ease` перед вызовом; допустимы только оценки от 1 до 4.

## `multi`

### Что делает

Выполняет несколько действий одним HTTP-запросом и возвращает массив результатов в исходном порядке. Это уменьшает число сетевых обращений к AnkiConnect.

```json
{
  "action": "multi",
  "version": 6,
  "params": {
    "actions": [
      { "action": "guiDeckReview", "params": { "name": "English::Verbs" } },
      { "action": "guiCurrentCard" }
    ]
  }
}
```

### Когда применять

Когда действия независимы или порядок уже достаточен, например: открыть review и сразу запросить текущую карточку. Не используйте `multi`, если следующее действие зависит от содержимого предыдущего ответа — например, нельзя безопасно выбрать `ease` для `guiAnswerCard`, пока не прочитаны `buttons` текущей карточки.

### Важный нюанс формата

Вложенные действия можно передавать без `version`: тогда их успешные результаты приходят «сырыми» (`true`, объект, массив). Если добавить `"version": 6` к конкретному вложенному действию, его элемент результата будет полным объектом `{ "result": …, "error": … }`. Выберите один стиль и обрабатывайте ответ последовательно.

## `getCollectionStatsHTML`

### Что делает

Возвращает статистический отчёт Anki в виде HTML-строки — это данные для отображения, а не структурированный JSON.

### Параметры

| Параметр | Тип | Обязателен | Значение |
|---|---:|:---:|---|
| `wholeCollection` | boolean | да | `true` — статистика по всей коллекции; `false` — по текущей выбранной колоде/контексту статистики Anki |

```json
{
  "action": "getCollectionStatsHTML",
  "version": 6,
  "params": { "wholeCollection": true }
}
```

### Когда применять

Когда нужен готовый отчёт для встраивания в WebView или сохранения как HTML. Если требуются числа для графиков, фильтрации или дальнейших вычислений, этот метод неудобен: HTML придётся разбирать. В таком случае лучше использовать специализированные статистические методы AnkiConnect.

## Быстрый выбор метода

| Задача | Метод |
|---|---|
| Начать стандартное повторение выбранной колоды | `guiDeckReview` |
| Прочитать показанную в Anki карточку | `guiCurrentCard` |
| Раскрыть ответ в Anki | `guiShowAnswer` |
| Поставить оценку текущей карточке из GUI | `guiAnswerCard` |
| Проставить оценки набору карточек по ID | `answerCards` |
| Отправить несколько независимых вызовов разом | `multi` |
| Получить готовую HTML-страницу статистики | `getCollectionStatsHTML` |
